# Artefactos

Los reportes de cada módulo en formato navegable, versionados aquí para que no dependan de un enlace externo.

| Fichero | Módulo | Qué cuenta |
|---|---|---|
| [`reporte-modulo-4.html`](reporte-modulo-4.html) | 4 | Los tres defectos que la suite en verde escondía, y qué separa verificar de especificar |
| [`reporte-cierre-defectos.html`](reporte-cierre-defectos.html) | 3 | Qué se arregló, por qué así, y qué estaba documentado sin corresponder con el código |

Cada uno tiene su equivalente en Markdown, que es la versión de referencia:

- `docs/reporte-modulo-4.md`
- `docs/reporte-cierre-defectos.md`

Se abren con doble clic desde el repositorio: son documentos HTML completos, sin dependencias externas salvo la hoja de tipografías de Google Fonts, que degrada a las fuentes del sistema si no hay red.
